The homepage strip identifies projects represented in the portfolio, with a work-type label and a link to each project story. It does not label research subjects or content samples as clients, employers or endorsements.

Logos are stored locally in `public/images/brands`. Source URLs and the content displayed in the strip are maintained in `src/data/projects.ts` under `brandShowcase`.

- Harmonix, Mantle and Morpho: official website header SVGs, retrieved 2026-10-21. Removed website-specific CSS class attributes; Morpho's inherited `currentColor` and Harmonix's lettering use white for readability on the portfolio's dark background. The Harmonix symbol retains its original colors.
- Sui: official website's `logo-sui.svg` asset at https://cdn.prod.website-files.com/68e8e0120513ba12c5cd12e0/691b669368b8677fe201e79a_logo-sui.svg, retrieved 2026-10-21.

LayerZero, Kalshi and Ronin were subsequently supplied locally by the user from the Desktop `ifeoluwa-portfolio` folder. Original files are copied without raster modifications. LayerZero uses a CSS filter for white lettering on the dark background; Kalshi uses a centered cover fit.
